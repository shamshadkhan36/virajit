# Viraj IT — Laptop Brands page wireframe

Open `index.html` in a browser to review the responsive page. This is a local design handoff, not a published page or a product catalogue.

## Page journey

Discover the four brands → choose a use case → understand the local-store advantage → enquire by WhatsApp or plan a visit. FAQ and contextual links answer remaining questions without adding models, prices, stock counts or checkout.

## Before publication

- Replace text logo slots with approved Dell, Acer, MSI and Epson logo assets.
- Verify each partner title and usage rights before adding it to a brand card. The wireframe intentionally does not assert those credentials.
- Replace the hero illustration and store-photo placeholder with approved category imagery and genuine Viraj IT photography.
- Confirm the full store address, opening hours and Google Business Profile directions link. The directions URL in the wireframe comes from the current Viraj IT site and should be checked.
- Confirm the WhatsApp number `+91 89287 15729`, plus current warranty and EMI policies, before updating FAQ answers.
- When integrating into the production codebase, replace this standalone header/footer with the site's shared components and use its actual design tokens. The local prototype in this workspace uses an older green identity; this wireframe follows the magenta, plum and light-neutral palette observed on the current live site.

## Interaction notes

- Brand-specific WhatsApp messages are prefilled. The general WhatsApp and phone links are also functional.
- The FAQ uses native `details` elements for keyboard-friendly disclosure.
- Mobile navigation uses a native `details` menu. If integrated into a framework, preserve the same keyboard and focus behavior.
- The Visit Store hero button and location CTA open the directions link currently used by the live site. Confirm that link before publication.
