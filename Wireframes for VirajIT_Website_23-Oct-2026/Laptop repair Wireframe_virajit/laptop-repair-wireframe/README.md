# Viraj IT — Laptop Repair page wireframe

Open `index.html` in a browser. This local wireframe uses the shared design styles in `../laptop-brands-wireframe/styles.css`; keep the folders together when sharing it. The intended production URL remains `/laptop-repair-store-in-mumbai`.

## Page journey

Repair enquiry → identify the problem → understand motherboard expertise and the repair process → see documented work → visit or contact the store. The business AMC section is a compact cross-link.

## Reuse during production integration

- Preserve the current repair URL, shared header/footer, floating WhatsApp, analytics, and any working SEO metadata.
- Replace wireframe photography blocks with genuine Viraj IT workshop, inspection and completed-repair photographs. The three story cards are content slots, not actual customer cases.
- Add only verified repair-specific Google reviews, with original wording.
- Replace the AMC cross-link with `/computer-amc-services-mumbai` when that page exists. The wireframe currently points to the live repair page's existing `#amc` section.
- Keep the repair journey free of unconfirmed promises. The current live page makes claims about free diagnosis, same-day screen turnaround, warranty and laptop-on-loan availability; these have been deliberately omitted pending confirmation.

## Verify before publication

- The store address and directions link carried over from the current live site, plus business hours and phone numbers.
- Diagnostic charges, repair times, spare-part sourcing, repair warranty, data-handling process and eligibility for chip-level repair.
- Whether the site will offer repair booking or use WhatsApp solely for enquiries. The wireframe's WhatsApp message asks the team how to get the laptop checked; it does not claim a booking was completed.

This is a local design source for review. The live repair page was not changed.
